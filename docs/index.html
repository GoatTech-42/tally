GoNuts · October 26, 2026

Public support has ended.

After seven weeks of development, GoNuts is no longer publicly maintained or supported.

The source code and existing releases remain available. Anyone wishing to fix bugs, add features or maintain the project is welcome to fork the repository. The original developer will no longer provide public support or updates.

The final standalone client retains local trading and recovery safeguards. Swarm, the hosted dashboard, bug reporting and diagnostic uploads are retired. Shared discovery and remote dashboard features are no longer available.

  • Source code — fork and maintain your own version
  • Existing releases and downloads
  • Static GitHub Pages documentation
  • Release history

Keep your local database, settings and recovery records when updating. There is no public support service.
