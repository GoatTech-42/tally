# Public support retired

After seven weeks of development, GoNuts is no longer publicly maintained or supported.
The source code and existing releases remain available. Anyone wishing to fix bugs,
add features or maintain the project is welcome to fork the repository. The original
developer will no longer provide public support or updates.

The final standalone client does not connect to the retired Swarm, hosted dashboard,
bug reporting or diagnostic upload services. Local trading, market history, settings,
ownership records and recovery safeguards remain. Shared discovery/history and remote
dashboard features are unavailable. GitHub downloads and the static documentation remain.
Do not delete your local database or reset recovery records when updating.

* Source and forks: https://github.com/cody-raves/Gonuts
* Downloads: https://github.com/cody-raves/Gonuts/releases/latest
* Static documentation: https://cody-raves.github.io/Gonuts/
